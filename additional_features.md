# Additional Features

These features are intentionally outside `prompt.txt`, but are useful for making the prototype easier to operate.

## Interactive Allocation CLI

Command:

```bash
uv run degree-auditor interactive-allocate \
  --config configs/nus_ee_ay24_jc \
  --transcript examples/transcripts/simple_completed.yaml \
  --out tmp/allocation.yaml
```

The command expands allocation possibilities for each transcript course and prompts for one or more numbered choices in the terminal. A blank answer defaults to `UE_RESIDUAL` when that option is available. Entering multiple numbers allocates the same course to multiple requirements and marks those explicit allocations as `double_count`.

The generated YAML is readable by the normal `--allocation` audit flow and includes comments that show the eligibility expansion used during prompting:

```yaml
# Generated by degree-auditor interactive-allocate.
# Eligibility comments list possible allocation targets shown during selection.
allocations:
  # EE4308 eligibility: EE24JC_TE, RBT_ELECTIVES_20_UNITS, UE_RESIDUAL, IGNORED
  - course_code: EE4308
    requirement_id: EE24JC_TE
    units: 4
    allocation_role: primary
    manual: true
```

You can optionally run the audit immediately after writing the allocation YAML:

```bash
uv run degree-auditor interactive-allocate \
  --config configs/nus_ee_ay24_jc \
  --transcript examples/transcripts/simple_completed.yaml \
  --out tmp/allocation.yaml \
  --audit
```

Use JSON audit output with:

```bash
uv run degree-auditor interactive-allocate \
  --config configs/nus_ee_ay24_jc \
  --transcript examples/transcripts/simple_completed.yaml \
  --out tmp/allocation.yaml \
  --audit \
  --audit-format json
```

Limitations:

- This is a prompt-loop interface, not a full-screen terminal UI.
- It does not optimise or auto-complete a valid study plan; the user remains responsible for selecting enough major, TC, TE, and specialisation allocations.
- The commented YAML writer is specific to `interactive-allocate`; `plan-allocation` still emits plain YAML.
